# 桥跨工况簿

桥梁静载试验的本地数据复核工作台。导入试验计划、逐轴驻位和位移采样后，可以核对驻位是否符合计划，按空载、驻载、撤载归约位移，检查断面包络与重复性，并签出含原始行和裁定记录的证据包。

## 启动

需要 Python 3.9 或更高版本和支持 ES modules 的浏览器。启动过程使用 Python 标准库、SQLite 和原生浏览器 API，无须安装依赖。

```sh
python3 -B -m girder
```

打开浏览器中的 `http://127.0.0.1:8765`。服务只监听本机回环。默认数据库为 `var/girder.sqlite`，可用 `--port` 和 `--db` 指定端口和文件。

## 演练

1. 点击「载入演练样本」，或手动导入 `examples` 内的三份文件。
2. 在「工况复核」打开 H1 的跨中内侧测点 `MID_I`。驻载位移应为 −119 μm，撤载残余应为 4 μm。证据面板同时列出逐轴驻位、同刻配对和源 CSV 行号。
3. 在「断面与复测」查看同工况跨中内侧重复差 16 μm，以及跨中断面下界 −150 μm 对应的控制轮次。
4. 在「签出与比对」签出代次 0。在「原始记录」找到 `REF_A-21` 并附理由排除。签出代次 1，再比对两版。H1 的 `MID_I` 驻载变化应为 +1 μm。两版的「查看」分别打开各自的归档证据。
5. 排除 `REF_A-24` 后，H1 使用该参考的 `Q1` 和 `MID_I` 证据不足，签出不可用。通过逐行裁定记录恢复该行即可重新签出。

样本是合成记录。复核提示和签出状态描述数据覆盖与处理结果，工程验收仍需结合实际试验规程和现场记录。

## 代码与验证

- `girder/` 放置输入解析、驻位核对、配对和归约、持久化及 HTTP 模块。`web/` 放置原生 HTML、CSS 和 JavaScript 模块。数据处理由后端统一完成。
- `PROJECT_SPEC.md` 记录输入合同、结果定义和 HTTP 入口。

```sh
python3 -B -m tools.build
python3 -B -m tools.verify_workflow
```

构建检查编译 Python 源文件并读取页面资源。工作流检查使用临时 SQLite 数据库和回环 HTTP 服务，覆盖导入、归约、裁定、签出、比对及历史追溯。
